## ✨ ماذا يفعل؟

- اكتب كلماتك (كل سطر = جملة غنائية) واضغط **«اصنع الأغنية»**.
- يولّد الموقع **موسيقى كاملة إجرائيًا** (Web Audio API): إيقاع، باص 808، جيتار مشوَّه، أوتار، كورال، شرقيات…
- يغنّي الكلمات عبر محرّك النطق المدمج في متصفحك (Web Speech API) بصوت تختاره أنت.
- حمّل النتيجة **WAV** عالي الجودة + ملف كلمات TXT + صفحة HTML أنيقة.

## 🚀 التشغيل

افتح `index.html` في متصفحك مباشرة — أو قدّم المجلد بأي سيرفر ثابت:

```bash
python3 -m http.server 8099
```

ثم افتح `http://localhost:8099`.

## 🧰 تقنيًا

- **الموسيقى**: محرّك DSP مكتوب يدويًا (تخليق عينات مباشر في JavaScript) + سلسلة ماستر
  (كومبريسور + ليميتر + ريفرب convolution + ديلاي) — مصدر صوتي واحد لكل مازورة = تصنيع سريع (~ثوانٍ).
- **الغناء**: Web Speech API مع ضبط `pitch/rate` لكل شخصية صوتية، ومزامنة على الإيقاع.
- **التصدير**: OfflineAudioContext → ترميز WAV‏ 16-bit/44.1kHz ستيريو.
- لا مكتبات خارجية، لا CDN إلزامي، يعمل دون إنترنت بعد الفتح.
